# Preservation and investigation material

- `original-as2/`: JPEXS export of the unmodified game's ActionScript.
- `original-text/`: Original text assets exported by JPEXS.
- `original.xml`: XML representation of the original SWF.
- `downloads/`: Pinned Ruffle and JPEXS distribution archives; provenance and
  checksums are in `../assets/SOURCES.md`.
- `initial-browser-check/`: Historical screenshots from the initial deployment
  and early form debugging. These do not represent the final community build.

Current browser verification screenshots are generated in
`../tests/browser/artifacts/`. Edit `../scripts/` to change the community build;
the original exports here are reference material.
